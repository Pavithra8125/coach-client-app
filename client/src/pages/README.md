**Built so far**

- `ClientList.jsx` — dashboard: all clients at a glance, add/edit/delete (slice 2)
- `ClientDetail.jsx` — individual client profile; progress (slice 3), workout
  plan/log/overload+PR (slice 4), and diet (slice 5) sections render inside here
