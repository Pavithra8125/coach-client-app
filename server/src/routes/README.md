# API routes

Feature endpoints live here, one file per domain, mounted in `src/app.js`.
Planned (added as the matching build slice lands):

- `auth.js` — login, logout, current-session check
- `clients.js` — client CRUD
- `workouts.js` — plans, logged workouts, progressive overload, PRs
- `diet.js` — meal plans, food log, water, supplements
- `progress.js` — weight/measurements
- `checkins.js` — weekly check-ins (slice 6)
- `coachNotes.js` — coach's log notes (slice 6)
- `exercises.js` — shared exercise library (slice 4)

Still planned: progress photos, dashboard summary, gamification, personal layer.
